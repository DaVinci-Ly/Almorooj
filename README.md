# موقع شركة المروج الخضراء العريقة

موقع تعريفي لشركة **المروج الخضراء العريقة لصناعة الدقيق ومطاحن الأعلاف**،
بالعربية والإنجليزية، مبني بملفات ثابتة (HTML / CSS / JavaScript) بدون أي مكتبات خارجية
أو مرحلة بناء، ومهيّأ للنشر على GitHub Pages.

## تشغيل الموقع محلياً

الموقع ملفات ثابتة، لكن فتح `index.html` مباشرة من القرص يمنع تحميل بعض الملفات.
شغّل خادماً محلياً بسيطاً:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>. لا يوجد `npm install` ولا خطوة بناء.

```

├── about.html               من نحن
├── products.html            المنتجات
├── contact.html             اتصل بنا
├── 404.html                 صفحة الخطأ

│   ├── index.html

│   ├── products.html
│   └── contact.html
│
├── assets/
│   ├── css/
│   │   ├── fonts.css        تعريف الخط المستضاف محلياً
│   │   ├── base.css         متغيّرات الألوان والمسافات، إعادة الضبط، التيبوغرافيا، الشبكة
│   │   └── components.css   الترويسة، الأزرار، البطاقات، النماذج، التذييل
│   ├── js/
│   │   └── main.js          القائمة، ظهور العناصر، والنموذج
│   ├── fonts/               IBM Plex Sans Arabic بصيغة woff2 (عربي + لاتيني)
│   └── img/                 الشعار، الأيقونات، الرسومات التوضيحية، الأنماط
│
├── site.webmanifest         بيانات التطبيق للجوال
├── robots.txt               تعليمات محركات البحث
├── sitemap.xml              خريطة الموقع
├── .nojekyll                يمنع GitHub من معالجة الملفات بمحرّك Jekyll
├── CONTENT-TODO.md          البيانات الناقصة وأماكن استبدالها
└── .github/workflows/       النشر التلقائي
```

### لماذا هذه البنية

- **لا مرحلة بناء**: ما تراه في المستودع هو ما يُنشر بالضبط. أي شخص يقدر يفتح ملفاً ويعدّله.
- **مسارات نسبية**: الصفحات تستخدم `assets/…` و`../assets/…` بدل المسارات المطلقة،
  فيعمل الموقع سواء على نطاق خاص أو على رابط GitHub الفرعي.
- **خط مستضاف محلياً**: لا طلب لأي خادم خارجي عند فتح الصفحة — أسرع، وأفضل للخصوصية.
- **بلا خرائط مضمّنة**: بطاقة الموقع رابط مباشر إلى خرائط جوجل — يفتح التطبيق على الجوال
  وتبويباً جديداً على الحاسوب. لا إطار مضمّن ولا طلب لأي طرف ثالث.

## تعديل المحتوى

### النصوص

كل النصوص مكتوبة مباشرة داخل ملفات HTML. افتح الصفحة المطلوبة وعدّل النص بين الوسوم.
لا توجد قاعدة بيانات ولا ملفات ترجمة.

> عند تعديل نص في صفحة عربية، لا تنسَ تعديل مقابله في `en/`.

### الترويسة والتذييل

الترويسة والتذييل مكرّران في كل صفحة (هذا ثمن العمل بدون مرحلة بناء).
عند تغيير شيء فيهما — مثل رقم الهاتف — استخدم البحث والاستبدال على كل الملفات:

```bash
grep -rl "النص القديم" --include="*.html" . | xargs sed -i '' 's/النص القديم/النص الجديد/g'
```

### موقع المصنع على الخريطة

بطاقة الموقع في الرئيسية وصفحة الاتصال ترتبط بخرائط جوجل عبر الإحداثيات مباشرة:

```
https://www.google.com/maps/search/?api=1&query=32.711167,13.8285
```

لتغيير الموقع، بدّل الإحداثيات في هذا الرابط في الملفات الأربعة
(`index.html`, `contact.html`, `en/index.html`, `en/contact.html`)
وفي بيانات `geo` و`hasMap` المنظّمة داخل الصفحتين الرئيسيتين.

### البيانات الناقصة

راجع [CONTENT-TODO.md](CONTENT-TODO.md) — فيه جدول بكل قيمة مؤقتة وأين تظهر.

## الهوية البصرية

### الألوان

مستخرجة مباشرة من شعار الشركة، ومعرّفة كلها في مكان واحد:
[`assets/css/base.css`](assets/css/base.css) داخل `:root`.

| المتغيّر | اللون | مصدره في الشعار |
|---|---|---|
| `--c-brown` | `#2f0f06` | الإطار الخارجي والخط |
| `--c-sage` | `#5c857b` | السنابل الجانبية |
| `--c-gold-bright` | `#cdb376` | السنابل الوسطى |
| `--c-taupe` | `#9c918a` | الترس |
| `--c-sand` | `#fbf8f3` | خلفية الصفحات |

تغيير أي لون في هذا المكان ينعكس على الموقع كله.

### الخط

**IBM Plex Sans Arabic** بأوزان 400 / 500 / 600 / 700، مستضاف محلياً في `assets/fonts/`
(رخصة SIL Open Font License 1.1). النطاقان العربي واللاتيني فقط — الحجم الكلي ~208 كيلوبايت.

### الشعار

الشعار الرسمي للشركة، مستخرَج من الملف الأصلي بخلفية شفافة:

| الملف | الحجم | الاستخدام |
|---|---|---|
| `logo-small.png` | 160×160 | الترويسة والتذييل في كل الصفحات |
| `logo.png` | 512×512 | البيانات المنظّمة والمرجع عالي الدقة |
| `favicon.svg` | متجه | أيقونة المتصفّح — نسخة مبسّطة تبقى مقروءة بحجم 16px |
| `favicon-32/192/512.png` | — | أيقونات احتياطية وأيقونة التطبيق |
| `apple-touch-icon.png` | 180×180 | أيقونة الشاشة الرئيسية في iOS |
| `og-image.png` | 1200×630 | صورة المشاركة على واتساب وفيسبوك |

لتحديث الشعار: استبدل `logo.png` و`logo-small.png` بنفس الأسماء والأبعاد المربّعة.

### الرسومات التوضيحية

كل الرسومات ملفات SVG مرسومة يدوياً بألوان الهوية، حجم كل منها بضعة كيلوبايتات فقط:

| الملف | الاستخدام |
|---|---|
| `illus-hero.svg` | واجهة الصفحة الرئيسية |
| `illus-flour.svg` | دقيق القمح |
| `illus-semolina.svg` | السميد والنخالة |
| `illus-feed.svg` | الأعلاف المركّزة |
| `illus-mill.svg` | المصنع (صفحة من نحن) |
| `illus-quality.svg` | فحص الجودة |
| `pattern-wheat.svg` | نمط الخلفية الفاتح |
| `pattern-wheat-light.svg` | نمط الخلفية فوق الأقسام الداكنة |

عند توفّر صور فوتوغرافية حقيقية للمصنع، يمكن استبدال هذه الرسومات تدريجياً.

## النشر على GitHub Pages

مضبوط للنشر التلقائي عبر [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):
كل دفعة إلى الفرع `main` تنشر الموقع.

**خطوة لمرة واحدة** — في المستودع على GitHub:

1. `Settings` → `Pages`
2. تحت **Source** اختر **GitHub Actions**

بعدها:

```bash
git add .
git commit -m "إطلاق الموقع"
git push origin main
```

تابع النشر من تبويب `Actions`. أول نشر يستغرق دقيقة تقريباً.

> **ملاحظة**: صفحة `404.html` تستخدم مسارات مطلقة (`/assets/…`)، وهي تعمل بشكل صحيح
> بعد ربط النطاق الخاص. على رابط `github.io` الفرعي ستظهر بدون تنسيق — وهذا طبيعي ومؤقت.

## ربط النطاق

بعد شراء النطاق:

**١. في المستودع** أنشئ ملف `CNAME` في الجذر يحتوي على سطر واحد فقط:

```
almorooj.ly
```

**٢. عند مزوّد النطاق** أضف هذه السجلات:

| النوع | الاسم | القيمة |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `davinci-ly.github.io` |

**٣. في GitHub**: `Settings` → `Pages` → ضع النطاق في **Custom domain**،
وانتظر حتى يتفعّل **Enforce HTTPS** (قد يستغرق حتى ٢٤ ساعة).

**٤. حدّث الروابط في الملفات** إن كان النطاق مختلفاً عن `almorooj.ly`:

```bash
grep -rl "almorooj.ly" --include="*.html" --include="*.xml" --include="*.txt" . \
  | xargs sed -i '' 's/almorooj\.ly/النطاق-الجديد/g'
```

## البريد الإلكتروني عبر Zoho

بعد ربط النطاق:

1. أنشئ حساباً على [Zoho Mail](https://www.zoho.com/mail/) واختر الخطة المجانية.
2. أضف نطاقك وأثبت ملكيته بسجل `TXT` يعطيك إياه Zoho.
3. أضف سجلات `MX` عند مزوّد النطاق:

   | الأولوية | القيمة |
   |---|---|
   | 10 | `mx.zoho.com` |
   | 20 | `mx2.zoho.com` |
   | 50 | `mx3.zoho.com` |

4. أضف سجلّي `SPF` و`DKIM` كما يعرضهما Zoho — بدونهما ستذهب رسائلك إلى مجلد الرسائل غير المرغوبة.
5. أنشئ صندوق `info@` ثم حدّث البريد في الموقع:

   ```bash
   grep -rl "info@almorooj.ly" --include="*.html" . \
     | xargs sed -i '' 's/info@almorooj\.ly/البريد-الجديد/g'
   ```

> سجلات `MX` للبريد و`A` للموقع منفصلة تماماً ولا تتعارض.

## تفعيل نموذج التواصل

الموقع ثابت بلا خادم، فلا يستطيع استقبال الرسائل بنفسه. الوضع الحالي:

- **افتراضياً**: الضغط على «إرسال» يفتح بريد الزائر برسالة جاهزة موجّهة إلى `info@almorooj.ly`.
  يعمل فوراً بلا إعداد، لكنه يعتمد على وجود برنامج بريد عند الزائر.
- **الأفضل**: استقبال الرسائل في بريدك مباشرة عبر خدمة مجانية:

  1. أنشئ نموذجاً على [Formspree](https://formspree.io) واربطه ببريدك.
  2. انسخ رابط النموذج وضعه في خاصية `action` في ملفَّي
     [`contact.html`](contact.html) و[`en/contact.html`](en/contact.html):

     ```html
     <form class="form" data-contact-form action="https://formspree.io/f/xxxxxxx" method="post" …>
     ```

  الباقي يعمل تلقائياً: التحقق من الحقول، رسالة النجاح، ورسالة الخطأ.

## الظهور في محركات البحث

الموقع مهيّأ من ناحية الكود: عناوين ووصف لكل صفحة، روابط أساسية، بيانات منظّمة
(Organization و FAQPage)، خريطة موقع، وروابط `hreflang` تربط النسختين العربية والإنجليزية.

**الخطوات المتبقّية بعد النشر وربط النطاق:**

1. **Google Search Console** — أضف النطاق، أثبت الملكية، وأرسل `sitemap.xml`.
2. **Bing Webmaster Tools** — الشيء نفسه (يمكن استيراد الإعدادات من Google مباشرة).
3. **الملف التجاري على خرائط Google** — أنشئ Google Business Profile للشركة.
   هذا أكثر ما يفيد الظهور في البحث المحلي، أكثر من أي تعديل في الموقع.
4. **حدّث `sitemap.xml`** — غيّر تاريخ `lastmod` عند أي تعديل كبير على المحتوى.

**نقاط تحسّن الترتيب لاحقاً:**

- صور حقيقية للمصنع والمنتجات بدل الرسومات.
- صفحة أخبار أو مقالات قصيرة تُحدَّث بين حين وآخر.
- ذكر المدينة والمناطق التي تخدمها الشركة صراحةً في النصوص.

## الأداء وإمكانية الوصول

ما هو مطبّق في الكود:

- خط مستضاف محلياً مع `preload` للوزنين الأكثر استخداماً.
- الصور والرسومات بأبعاد معرّفة مسبقاً لمنع اهتزاز الصفحة أثناء التحميل.
- `loading="lazy"` لكل ما هو أسفل الشاشة الأولى.
- لا خرائط مضمّنة — بطاقة الموقع رابط مباشر إلى خرائط جوجل.
- تباين ألوان مناسب، وتنقّل كامل بلوحة المفاتيح مع حلقة تركيز واضحة.
- دعم `prefers-reduced-motion` لمن يفضّل تقليل الحركة.
- نسخة `noscript` تُظهر كل المحتوى إذا تعطّل الجافاسكربت.
- تنسيق مخصّص للطباعة على الورق.
